# OpenSurf

OpenSurf is an open-source ocean conditions and forecasting project.

The goal is to make ocean conditions easier to understand, easier to share, and easier to build on.

## What this site will hold

- project updates and build notes
- a lightweight surf conditions web app
- documentation as the project grows

## Current status

OpenSurf is in early development. The first pieces are focused on parsing ocean condition data, building a simple interface, and documenting the process along the way.
