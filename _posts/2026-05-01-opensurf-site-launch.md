Today I finished setting up the OpenSurf website using Jekyll and GitHub Pages! Stoked to have this little piece of infrastructure completed. 

The goal of OpenSurf is to make ocean conditions easier to understand, share, and build on for free. 

Right now the project includes:

- a CLI tool for surf conditions (located in my GitHub)
- a simple website to document progress (completed today)
- a placeholder for a future web app

Next steps:

- connect real-time data to the site
- start building the web interface
- continue documenting the process

If you're interested in ocean data or open-source tools, follow along 🤙
